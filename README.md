# React + TypeScript + Vite

This project uses React, TypeScript, and Vite with ESLint and Prettier.

## Code style

ESLint checks the code and sorts imports; Prettier formats files and sorts Tailwind
CSS classes. In VS Code, formatting and ESLint fixes run automatically when you
save a file. The workspace recommends the ESLint and Prettier extensions.

Use `@/` to import files from `src/`, for example `@/components/Button`.

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

Run `pnpm lint` to check the code, `pnpm format` to format it, or
`pnpm format:check` to verify formatting without changing files.
